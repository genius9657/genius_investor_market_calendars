# Genius Investor Market Calendars

This repository publishes an automatically generated JSON calendar for the
global exchanges used by Genius Investor.

The workflow runs every day at 01:17 UTC and can also be started manually from
the GitHub Actions tab. It uses the MIT-licensed
`apptastic-software/trading-calendar` project.

Generated data:

`data/market_calendars.json`

Flutter download URL after the first successful workflow run:

`https://raw.githubusercontent.com/genius9657/genius_investor_market_calendars/main/data/market_calendars.json`

No application source code, API key, or user data belongs in this repository.
